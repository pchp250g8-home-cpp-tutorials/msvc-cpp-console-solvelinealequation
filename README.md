Консольное приложение написанное на языке программирования C++. 
Программа делает следующее:
  1. Просит ввести коэффицееты линейного уравнения, которое нужно решить.
  2. Выводит на экран запись решаемое уравнение в линейной форме.
  3. Проверяет введённые коэффициенты на равенство 0.
  4. Далее возможны следующие случаи:
       1. Все коэффициенты равны нулю. На экран будет вывенена фраза на английском языке "Решение - любое число".
       2. Коэффициент "a" равен нулю, а "b" нет. В данном случае будет выдано собщение "Уравнение не имеет решений".
       3. Во всех остальных случаях на экран будет выведено решение, вычисляемое по формуле "x=-b/a" 
Разработано в интегрированной среде Microsoft Visual Studio.
